# Surface: studio main screen (write + record + catalogue)

Scope: the app's main screen on every size class (phone, unfolded foldable/tablet, desktop), plus the screens that inherit it (library/catalogue, song detail, extend, model setup). Mode: Operate.
Audience/job: write style + lyrics, record (generate) a song, watch the take while it renders or walk away, find songs by catalogue number, extend keepers.
Constraints: minimal text on main screens; licence and model info only in the model download step; hide unsupported features per model capability; no DAW look, no settings soup, no stock Material.
Approved comp: .impeccable/mocks/comp-3.webp (comp round, approved by user 2026-10-16). Decision card: Catalogue Sleeve (challenger, seed 3fa1913f).

## Direction contract

THESIS: Every song is a numbered catalogue entry (LRS-001…) whose face is a polar pulse plot of its own waveform; the studio is a catalogue, not a chat box or a DAW. Refuses the prompt-box-plus-Create-button feed and the knobs-and-meters console.

OWN-WORLD: Matte black ground, white 1px hairline frames and rules, wide-tracked engraved uppercase sans for labels, a plain grotesk for lyrics and values. A five-block colour code strip (grey, blue #3F6E8C, gold #D8A461, red #C8553D, white) per song, derived from its seed. Red marks the one active/current entry only. No gradients, no glow, no rounded cards.

STORY: The user sees the current take as a living polar plot, writes the next song below it, presses Record, and later finds every song by its number in the catalogue index.

FIRST VIEWPORT: Top third: circular polar pulse plot (radial hairline grid) of the current/last take, progress arc while recording, status line in engraved caps "RECORDING · LRS-015 · 2:14 / 4:00" between hairline rules. Middle: STYLE label + style text, LYRICS label + lyric sheet with section tags. Bottom: colour code strip, then the catalogue index bar (012 013 014 015) with the current entry framed red; Record is the primary action adjacent to the index.

FORM: Catalogue Sleeve (post-punk catalogue identity), challenger chosen by user over assigned Centre Label & Deadwax; seed key 3fa1913f.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
